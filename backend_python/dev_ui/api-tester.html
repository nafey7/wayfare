Guest Information

💳 Payments - Stripe Integration

POST /api/payments/create-intent
Create payment intent for flight booking (5% platform fee)
GET /api/payments/transaction/{payment_intent_id}
Get transaction details by payment intent ID
POST /api/payments/payouts/release
Release payout to supplier (Admin only)
ℹ️ Payment Flow:
  1. Create payment intent with booking amount
  2. Frontend uses client_secret with Stripe.js to collect payment
  3. User completes payment (handled by Stripe)
  4. Get transaction to verify payment status
  5. Admin releases payout to supplier after service delivery

Platform Fee: 5% automatically calculated and held
Supplier Amount: 95% transferred to supplier account
