# Admin Dashboard for Voya

**📖 For complete documentation, see `CLAUDE.md` in this directory.**

## Purpose

Administrative dashboard for managing Voya platform operations:
- User management and permissions
- Booking oversight and management
- System analytics and monitoring
- Platform configuration

## Quick Start

```bash
cd admin
npm install
npm start
```

Access at: http://localhost:3002

## Documentation

See `CLAUDE.md` for:
- Complete setup instructions
- Admin API endpoints and authentication
- Component structure and patterns
- User management workflows
- Booking management features
- Security considerations and audit logging

## Admin Features

- **User Management**: View, search, filter, and manage user accounts
- **Booking Management**: Monitor and manage flight bookings
- **System Settings**: Configure platform settings and email templates
- **Analytics**: User metrics, booking statistics, revenue tracking

## API Documentation

The admin dashboard connects to backend admin endpoints:
- **API Docs**: http://localhost:8000/api/docs (see `/api/admin/*` endpoints)
- **Base URL**: http://localhost:8000/api/admin
